# Object Analysis - Renewed

The Objects Analysis ability for Starsector 0.98a, without its frame rate cost.

Hover the Objects Analysis ability on the ability bar to list the objects in the current star system
that a scan could pick up (stations and neutrino sources), without their locations.

Based on Harpuea's Objects Analysis 002. That version scanned the whole star system every frame to
decide whether the ability could be switched on (it never can). This one only builds the list when
you hover the ability.

Replaces Objects Analysis: turn that mod off. Safe to add to or remove from a running save.
