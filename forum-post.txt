[center][b]
WHAT DOES THIS MOD DO?
The Objects Analysis ability from Harpuea's Objects Analysis, without its frame rate cost.
[/b][/center]
[center]
[hr][center][size=12pt][b]The Ability[/b][/size][/center][hr]
[list]
[li]Hover Objects Analysis on your ability bar to list the objects in the current star system: derelicts, caches, abandoned stations, gates and other things worth finding. Colony stations and clutter are left out, repeats are grouped, found objects are gray.[/li]
[li]It does not say where they are.[/li]
[li]Click it to scan: the fleet stops for about 5 seconds, then every object in the system is discovered and named on the map. Costs 5 volatiles by default.[/li]
[li]Works only inside star systems.[/li]
[/list]

[hr][center][size=12pt][b]Settings (LunaLib, optional)[/b][/size][/center][hr]
[list]
[li][b]Detail:[/b] Precise (default) shows derelict ships by name and class and fleets by name. Normal shows objects by the names the game uses and counts fleets as hostile, neutral and friendly. Vague only says whether something can still be salvaged, and how many fleets there are.[/li]
[li][b]Show fleets:[/b] on by default.[/li]
[li][b]Gray out found objects:[/b] on by default.[/li]
[li][b]Active scan:[/b] on by default. [b]Scan cost:[/b] volatiles, transplutonics or nothing, and how many.[/li]
[/list]

[hr][center][size=12pt][b]What Changed[/b][/size][/center][hr]
[list]
[li]The original scanned the whole star system every frame to check whether the ability could be switched on. It never can. With many objects in a system that cost about 7% of every frame on the campaign map.[/li]
[li]Now nothing runs until you hover the ability, and the list is built with far fewer searches.[/li]
[/list]

[hr][center][size=12pt][b]Compatibility[/b][/size][/center][hr]
[list]
[li]Replaces Objects Analysis: turn that mod off. With both on, the game stops at start and tells you.[/li]
[li]Same ability, so it keeps its place on your ability bar.[/li]
[li]Safe to add to or remove from a game in progress.[/li]
[/list]

[spoiler=Version log]
[b]1.2.0[/b]
[list][li]New: Active scan (LunaLib setting, on by default). Click the ability inside a star system: the fleet stops for about 5 seconds and is easier to see, then every object in the system is discovered as if you had flown up to it: named on the map, with the Discovered message and experience. Each scan costs 5 volatiles by default (setting: volatiles, transplutonics or nothing, and the amount). 1 day cooldown.[/li]
[li]The list no longer flickers: it always shows everything, without the original's random skip.[/li]
[li]The list no longer shows stellar mirrors and shades, fusion lamps, colony stations (orbital stations, battlestations, star fortresses and station colonies), or What We Left Behind's anti-asteroid satellites. Gates stay.[/li]
[li]Repeats are grouped: "Debris Field x4".[/li]
[li]New setting Gray out found objects (on by default): objects you have already found show in gray.[/li]
[li]Works only inside star systems: no list and no scan in hyperspace.[/li][/list]
[b]1.1.0[/b]
[list][li]New LunaLib setting Detail (Precise by default). Precise shows derelict ships by name and class, such as "ISS Hamatsu, Legion-class Carrier". Normal shows objects as before. Vague only says whether something in the system can still be salvaged.[/li]
[li]New LunaLib setting Show fleets (on by default): the tooltip also lists the fleets in the system. Precise names each fleet, Normal counts hostile, neutral and friendly fleets, Vague gives one total. In hyperspace only fleets within one map grid cell count.[/li]
[li]LunaLib is optional: without it the defaults apply.[/li][/list]
[b]1.0.0[/b]
[list][li]First release: the Objects Analysis ability from Harpuea's Objects Analysis 002, without its frame rate cost. The ability bar no longer scans the whole star system every frame. The object list is built only when you hover the ability.[/li]
[li]The list no longer starts each object name with a stray comma.[/li][/list]
[/spoiler]
