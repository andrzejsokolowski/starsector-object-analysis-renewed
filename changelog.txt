Version 1.1.0 (2026-11-15)
- New LunaLib setting Detail (Precise by default). Precise shows derelict ships by name and class, such as "ISS Hamatsu, Legion-class Carrier". Normal shows objects as before. Vague only says whether something in the system can still be salvaged.
- New LunaLib setting Show fleets (on by default): the tooltip also lists the fleets in the system. Precise names each fleet, Normal counts hostile, neutral and friendly fleets, Vague gives one total. In hyperspace only fleets within one map grid cell count.
- LunaLib is optional: without it the defaults apply.

Version 1.0.0 (2026-11-15)
- First release: the Objects Analysis ability from Harpuea's Objects Analysis 002, without its frame rate cost. The ability bar no longer scans the whole star system every frame. The object list is built only when you hover the ability.
- The list no longer starts each object name with a stray comma.
