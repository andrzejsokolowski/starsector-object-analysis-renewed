Version 1.3.1 (2026-11-15)
- Added the forum topic link for Version Checker.

Version 1.3.0 (2026-11-15)
- New LunaLib setting Planet survey (Preliminary by default): the active scan also surveys every planet in the star system. Preliminary gives each planet a preliminary survey, Full surveys each one fully (survey missions for it complete, but no survey data to sell), None leaves planets alone.

Version 1.2.0 (2026-11-15)
- New: Active scan (LunaLib setting, on by default). Click the ability inside a star system: the fleet stops for about 5 seconds and is easier to see, then every object in the system is discovered as if you had flown up to it: named on the map, with the Discovered message and experience. Each scan costs 5 volatiles by default (setting: volatiles, transplutonics or nothing, and the amount). 1 day cooldown.
- The list no longer flickers: it always shows everything, without the original's random skip.
- The list no longer shows stellar mirrors and shades, fusion lamps, colony stations (orbital stations, battlestations, star fortresses and station colonies), or What We Left Behind's anti-asteroid satellites. Gates stay.
- Repeats are grouped: "Debris Field x4".
- New setting Gray out found objects (on by default): objects you have already found show in gray.
- Works only inside star systems: no list and no scan in hyperspace.

Version 1.1.0 (2026-11-15)
- New LunaLib setting Detail (Precise by default). Precise shows derelict ships by name and class, such as "ISS Hamatsu, Legion-class Carrier". Normal shows objects as before. Vague only says whether something in the system can still be salvaged.
- New LunaLib setting Show fleets (on by default): the tooltip also lists the fleets in the system. Precise names each fleet, Normal counts hostile, neutral and friendly fleets, Vague gives one total. In hyperspace only fleets within one map grid cell count.
- LunaLib is optional: without it the defaults apply.

Version 1.0.0 (2026-11-15)
- First release: the Objects Analysis ability from Harpuea's Objects Analysis 002, without its frame rate cost. The ability bar no longer scans the whole star system every frame. The object list is built only when you hover the ability.
- The list no longer starts each object name with a stray comma.
